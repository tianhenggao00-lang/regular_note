# 记录中心模块设计规格

> 适用范围：自律小记 App「记录」Tab 下全部子模块。
> 关联文档：`docs/任务模块设计规格.md`（任务栏已定稿，本文件与其共用同一套视觉与颜色体系）。
> 状态：需求已收录，**三大设计决策已于 2026-08-31 确认**（见 §14）。

---

## 0. 信息架构总览

「记录」Tab 首页是一个 **2 行 × 5 列 = 10 格的 Hub 网格**，每格是一个模块入口：

```
[睡眠] [活动] [习惯] [饮食] [锻炼]
[记账] [收藏] [总结] [备忘录] [其他]
```

- **「其他」** 点进去再分三块：**纪念日 / 电子病历 / 灵感库**。
- 即：10 个主模块 + 其他里的 3 个子项 = 共 13 个功能点，但首页用 2×5 紧凑排布，不堆列表。
- 「今日」Tab 仅做 **汇总与快捷入口**（如：今日睡眠状态、饮食打卡、习惯进度、时间表卡片），点击下钻到「记录」对应子屏，避免重复维护。
- 「月历」作为跨模块通用时间视图，挂在「记录」顶部或「今日」入口，不单独占一格。

## 1. 睡眠（Sleep）

**目标**：回看近期睡眠节律，用颜色直观暴露"睡太少/太多"。

- **时间轴视图**：可切换 **近 7 天 / 近 30 天**。
  - 每行 = 一天：入睡时间、起床时间、总时长。
  - 用**颜色区分睡眠时长区间**（见 §13 颜色体系）：
    - < 6h 红；6–7h 橙；7–8h 绿；> 9h 蓝；7–8h 视为达标。
- **下方图表**：睡眠时长柱状图（横轴日期，纵轴小时数），叠加"达标线"（如 7.5h）。
- 数据录入：手动填入睡/起床时间（自动算时长），或导入手环数据（远期）。

**数据模型**
```json
{
  "date": "2026-08-31",
  "sleepTime": "23:40",
  "wakeTime": "07:10",
  "durationMin": 450,
  "quality": "良好"   // 可选：良好/一般/差
}
```

## 2. 活动（Activity）

分两类：**常用活动** 与 **活动表**。

### 2.1 常用活动
- 用户可**编辑**：增删改自己的常用活动，并**做好分类**（如 学习 / 运动 / 娱乐 / 杂务）。
- 每个活动是一张卡，带分类色。
- **双击（移动端=双指轻点/双击）卡片 → 自动开始计时**（见 §16 双击语义待确认）。
- 计时结束后，这段活动**以对应分类色显示在「活动表」的实际记录一侧**。

### 2.2 活动表
- 一条 **0:00–24:00 的时间轴**。
- **左半 = 理想安排**：每天早上划定的一日计划（与「今日」里的"时间表"卡片同源）。
- **右半 = 实际记录**：自动导入睡眠区间 + 用户记录的常用活动（含计时区间）。
- **不同分类用不同颜色**区分，一眼看清时间都花在哪。

**数据模型**
```json
// 常用活动
{ "id":"a1", "name":"高数", "category":"学习", "color":"#4F5BD5" }
// 一次计时记录
{ "activityId":"a1", "date":"2026-08-31", "start":"14:00", "end":"15:30", "durationMin":90 }
// 理想安排（一天的时间块）
{ "date":"2026-08-31", "blocks":[ {"category":"学习","start":"08:00","end":"10:00"} ] }
```

## 3. 习惯（Habits）

- 可**建造习惯卡片**。
- **每日习惯**分两种：
  - **好习惯**：双击 = 打卡成功（记一次完成）。
  - **坏习惯**：双击 = 触犯（记一次违规）。
- **每周 / 每月目标**：设定"每周完成 N 次 / 每月完成 N 次"，进度条显示当前周期内完成数。
- **年视图按钮**：点击进入年度视图。
  - 每个习惯一年 = 12 个月，每月**两排小格子**（按天）。
  - 做到了变**绿**，触犯了变**红**，未记录为灰。

**数据模型**
```json
{
  "id":"h1", "name":"早起", "type":"good",          // good / bad
  "cycle":"daily",                                  // daily / weekly / monthly
  "goalPerCycle": 7,                               // 周/月目标次数
  "records": { "2026-08-31":"done", "2026-09-01":"violated" }
}
```

## 4. 饮食（Diet）

- 记录**一日三餐**（早 / 午 / 晚，可扩展加餐）吃了什么。
- 每餐可选：**吃了 / 没吃**。
- **是否健康**：给几个固定选项让用户选（如 健康 / 一般 / 油腻 / 不均衡）。
- **饮水情况**：记录杯数或毫升。
- **拍照功能**：可拍一张当餐食物照片，留存每日食物样貌。

**数据模型**
```json
{
  "date":"2026-08-31",
  "meals":[
    {"type":"早餐","ate":true,"desc":"鸡蛋+牛奶","health":"健康","photo":null},
    {"type":"午餐","ate":true,"desc":"食堂","health":"一般","photo":"blob:key"}
  ],
  "waterMl": 1200
}
```
> 照片存 IndexedDB（localStorage 容量不够），见 §16。

## 5. 锻炼（Exercise）

- 记录锻炼情况：项目、时长、强度、消耗（可手填）。
- 展示**近一周锻炼情况**（柱状/频次图：几天练了、总时长）。

**数据模型**
```json
{ "date":"2026-08-31", "item":"跑步", "durationMin":40, "intensity":"中", "calorie":300 }
```

## 6. 记账（Accounting）

### 6.1 日常记账
- 记录今天花了多少钱 + 具体支出项（金额、分类、备注）。
- 分类如：餐饮 / 交通 / 学习 / 娱乐 / 其他。

### 6.2 月度规划
- 规划本月生活费总额，并分配到各板块预算。
- **圆形饼状图**直观划分各板块占比。

### 6.3 资产与日用品（三类分开，各自占比可见）
- **贵重设备**：记录拥有的贵重设备，统计总价。
- **会员费**：记录各项会员，统计总价（可显示"日均成本"）。
- **日用品**：记录每天日用品使用成本，计算**每日生活成本**。
- 三类**分开统计**，各自能看到"每种占多少"，再汇总出每日/每月生活成本。

### 6.4 存钱计划
- 制定存钱目标与周期，记录每次存入，进度条显示完成度。

**数据模型（节选）**
```json
// 支出
{ "date":"2026-08-31", "amount":25.0, "category":"餐饮", "note":"午饭" }
// 月预算
{ "month":"2026-08", "total":1500, "plan":{ "餐饮":600, "学习":300, "其他":600 } }
// 资产
{ "type":"device", "name":"笔记本", "value":8000 }
{ "type":"member", "name":"视频会员", "value":198, "perYear":true }
```

## 7. 收藏（Collection）

- 收藏喜欢的 **书籍 / 电影 / 音乐 / 爱好** 四类。
- 记录**收藏时间**。
- **爱好**可编辑**短评**（一段话）。

**数据模型**
```json
{ "kind":"书籍", "title":"xxx", "collectedAt":"2026-08-31", "review":"" }
{ "kind":"爱好", "title":"摄影", "collectedAt":"2026-08-31", "review":"今年想认真拍城市夜景" }
```

## 8. 总结（Summary）

- 每天输入一段"想对自己说的话"（自由文本，可带心情标签）。
- 与「今日」里的"每日总结"卡同源，这里为完整编辑页。

## 9. 备忘录（Memo）

- 记录**不足以作为任务、但需完成的小事**。
- 列表项可**上下移动**（拖拽重排，持久化）。
- 完成可勾选。

## 10. 其他（Others）

### 10.1 纪念日（参考「倒计日」App）
- 可添加纪念日，按类型区分：
  - **每年循环**：到后自动进入下一年循环（如生日、结婚纪念）。
  - **一次性**：过完后可删除（如某次考试）。
  - **每年浮动**：日期按规则浮动（母亲节、父亲节、端午节等），按年自动算具体日期。
- 列表显示**倒计时**（还有 N 天）。

### 10.2 电子病历
- 记录就诊情况：日期、医院、科室、诊断、用药、备注。

### 10.3 灵感库（必须像微信）
- 交互**仿微信聊天**：底部输入框，回车发送 → 自己的灵感以**气泡**形式出现在对话流（右对齐气泡）。
- 可长按气泡删除/编辑。

**数据模型**
```json
// 纪念日
{ "id":"m1", "title":"父亲节", "type":"floating", "rule":"6月第3个周日", "countdownDays":293 }
// 灵感
{ "id":"i1", "text":"做个睡眠+活动的联动卡片", "createdAt":"2026-08-31T11:20:00" }
```

## 11. 跨模块交互约定

| 交互 | 语义 |
|---|---|
| 双击（习惯卡） | 好习惯=打卡；坏习惯=触犯 |
| 双击（常用活动卡） | 开始计时 |
| 拖动（备忘录） | 上下重排 |
| 长按（灵感气泡） | 删除/编辑 |

> **双击实现（已确认）**：移动端保留"双击 / 双指轻点"手势，同时每张卡常显一个**按钮**作为备选（如习惯卡的"打卡"键、活动卡的"开始"键），防止误触与手势冲突。

## 14. 已确认的设计决策

1. **导航组织**：记录首页 = 2×5 Hub 网格（10 主模块 + 其他下钻 3 项）。（用户确认）
2. **视觉风格**：**A 底 + B 调 混搭** —— 功能屏（任务/活动/习惯/记账等）用 A 看板活力风（indigo 主色 + 类型色码 + 进度环 + 轻投影）；安静屏（睡眠/总结/灵感库）用 B 禅意素色（米白/墨绿/赭石、留白多、动效少）。（用户确认）
3. **手机双击**：保留双击/双指轻点，每张卡加常显按钮作备选。（用户确认）
