## 1. 产品定位与技术栈

- **平台**：Android 优先（底部 Tab + 手势返回）；移动端 390×844 基准，含状态栏 + 底栏。
- **技术栈**：纯 vanilla JS + localStorage（照片用 IndexedDB）。不引入框架。
- **交付路径**：设计稿 → 代码（HTML/JS）→ 部署 GitHub Pages → **PWABuilder** 出 APK → 手机安装。
- **全局约束**：不使用 emoji；状态/完成度用色块、进度条、字体权重表达。
- **跨端目标**：日记/总结可导出 Markdown 落入 Obsidian（`D:\500_else\520_Obsidian_record\personal_record` 的 `005日记`/`日记`）。

## 3. 记录中心（2×5 Hub）

首页 10 格，点「其他」再下钻 3 项：

```
[睡眠] [活动] [习惯] [饮食] [锻炼]
[记账] [收藏] [总结] [备忘录] [其他→纪念日/电子病历/灵感库]
```

| 模块 | 核心要点 |
|---|---|
| 睡眠 | 7/30 天时间轴；时长色码；下方时长柱状图 |
| 活动 | 常用活动(可编辑/分类/双击计时) + 活动表(0–24h，理想左/实际右，分类色) |
| 习惯 | 好/坏双击打卡；周月目标；年视图(每月两排小格，绿=成/红=犯) |
| 饮食 | 三餐 吃了/没吃 + 健康选项 + 饮水 + 拍照 |
| 锻炼 | 记录 + 近一周展示 |
| 记账 | 日常记账 + 月规划饼图 + 资产/日用品分算 + 存钱计划 |
| 收藏 | 书籍/电影/音乐/爱好 + 收藏时间 + 爱好短评 |
| 总结 | 每日自语 |
| 备忘录 | 小事清单 + 上下拖动 |
| 其他 | 纪念日(三类型+倒计时) / 电子病历 / 灵感库(微信风气泡) |

详细需求、数据模型、验收清单见 `docs/记录中心模块设计规格.md`。

## 4. 任务栏（已定稿）

- 两栏：待办池（唯一可新建/「+今日」处）+ 今日任务；移动端用**单栏 + 右下 FAB 切换**。
- 长线任务：按个数，`done/total` 用**进度环**；未全完成 → 次日自动回待办池。
- 短线任务：完成/未完成；未完成可勾「明日回池」→ 次日回池。
- 排序：按类型 / 按截止日期（顶部切换）；截止日期可设或无。
- 拖动：手柄垂直重排 + 释放挤开 + 持久化；左右滑动快捷（右滑加今日/完成，左滑明日回池）。
- 详细见 `docs/任务模块设计规格.md`。

## 5. 视觉风格（A 底 + B 调 混搭）

- **A 看板活力风（功能屏）**：indigo 主色 `#4F5BD5` + 类型色码 + 进度环 + 轻投影。用于 任务/活动/习惯/记账/收藏等。
- **B 禅意素色（安静屏）**：米白 `#FAF7F0` 底、墨绿 `#2F6B4F` / 赭石 `#B07A3F` 点缀、留白多、动效少。用于 睡眠/总结/灵感库。
- **类型色码**：学习 indigo / 运动 绿 / 生活 橙 / 工作 紫 / 其他 灰。
- **纪念日**：紫色高亮（沿用「今日」约定）。
- 设计稿中已落地的首版为平铺卡片风，正式稿将按此混搭重做。
